Simulator ini membantu memvisualisasikan tren pemberian dosis secara relatif. Alat ini ditujukan untuk edukasi dan pengurangan dampak buruk (harm reduction), bukan untuk perencanaan pengobatan yang dipersonalisasi.

:::caution[Penting]
Jangan gunakan simulator ini sebagai kalkulator resep pribadi. Selalu tafsirkan hasilnya bersama dengan hasil pemeriksaan darah, gejala, dan saran klinis.
:::

:::note[Status lokalisasi]
Antarmuka alat interaktif ini masih dalam proses lokalisasi. Beberapa label dan teks bantuan mungkin untuk sementara masih dalam bahasa Tionghoa.
:::
