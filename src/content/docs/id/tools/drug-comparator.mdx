## Perbandingan Obat

Pilih 2–3 obat untuk membandingkan parameter pentingnya secara cepat dan berdampingan.

**Alat ini membantu Anda memahami:**

- Perbedaan risiko VTE (tromboemboli vena) antara berbagai rute pemberian estrogen (oral, transdermal, atau injeksi)
- Kebutuhan pemantauan dan kontraindikasi obat anti-androgen
- Tingkat bukti dan rentang dosis untuk masing-masing obat

## Cara Membaca Hasilnya

- **Risiko VTE (RR)**: Nilai risiko relatif. RR=1.0 adalah garis dasar; nilai >1.5 menunjukkan peningkatan yang bermakna
- **Tingkat Bukti**: A = RCT/Meta-analisis, B = RCT tunggal/Studi kohort, C = Laporan kasus/Pendapat ahli
- **Pemantauan**: Pemeriksaan laboratorium yang perlu dilakukan selama menggunakan obat tersebut
