## Perbandingan Obat

Pilih 2-3 obat untuk membandingkan parameter utamanya dengan cepat.

**Alat ini membantu Anda memahami:**

- Perbedaan risiko VTE (tromboemboli vena) antara berbagai rute pemberian estrogen (oral vs transdermal vs injeksi)
- Persyaratan pemantauan dan kontraindikasi anti-androgen
- Tingkat bukti dan rentang dosis untuk setiap obat

## Cara Menafsirkan Hasil

- **Risiko VTE (RR)**: Nilai risiko relatif. RR=1.0 adalah nilai dasar; >1.5 menunjukkan peningkatan yang bermakna
- **Tingkat Bukti**: A = RCT/Meta-analisis, B = RCT tunggal/Studi kohort, C = Laporan kasus/Pendapat ahli
- **Pemantauan**: Pemeriksaan laboratorium yang diperlukan selama penggunaan obat
