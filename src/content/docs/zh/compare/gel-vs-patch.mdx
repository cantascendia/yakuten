雌二醇凝胶与透皮贴片均属于经皮给药方式。由于它们**完全绕过肝脏的首过代谢**，其深静脉血栓（VTE）的发生风险非常接近未用药人群的基线水平<CitationRef id="canonico-2018" />。在欧美医学界，这两种方案通常是 40 岁以上跨性别女性进行激素治疗（HRT）的首选。虽然目前在国内的获取难度相对高一些，但其出色的安全性依然值得你关注与了解。

:::note[30 秒决策矩阵]
| 我的情况是 → | 推荐选 |
|---|---|
| 皮肤敏感 / 有湿疹病史 / 贴片粘胶过敏 | **凝胶** · 接触面更小,无粘胶刺激 |
| 出汗多 / 健身 / 户外工作 | **贴片** · 无 4 小时禁淋浴窗口 |
| 想灵活微调剂量 (按泵数细调) | **凝胶** · 每泵约 0.75 mg E2 |
| 嫌每天涂麻烦 / 差旅多 / 作息不规律 | **贴片** · 每周 1-2 次,血药最稳 |
| 中国大陆易获取 (一线城市三甲) | **凝胶** · 爱斯妥可开,贴片需海淘 |
| 与婴儿/伴侣密切接触担心 transfer | **贴片** · 粘贴处转移风险极低 |
| 怀孕 / 哺乳 / 18 岁以下 | 都不推荐,请就医 |

> 不确定?继续阅读详细对比,或用 [风险自评](/zh/tools/risk-screener/) 辅助判断。
:::

## 一眼看懂

| 维度 | 凝胶(Oestrogel) | 贴片(Estraderm / Climara) |
|---|---|---|
| **给药频率** | 每日 1-2 次 | 每 3-7 天一次 |
| **剂量调整** | 灵活(泵数/按压数) | 受限(规格固定,可切半) |
| **血药稳定性** | 日内小波动 | 最稳定 |
| **皮肤反应** | 少见,局部泛红 | 10-20% 粘贴处瘙痒/红斑 |
| **Transfer 风险** | 涂抹后 4-6 小时内有 | 极低(粘贴处) |
| **游泳 / 淋浴** | 4 小时后可 | 部分贴片可,需确认说明 |
| **中国获取** | 部分三甲可开(爱斯妥) | 较难,多需海淘 |
| **每月成本** | 约 80-150 元 | 约 100-200 元 |

## 药代动力学

### 凝胶

涂抹于皮肤表面后，雌二醇会通过角质层逐渐扩散并进入毛细血管网。其血药浓度的变化规律如下<CitationRef id="kuhl-2005" />：

- 涂抹后约 4-6 小时，血液中的雌二醇浓度开始上升，约 10-12 小时达到峰值；
- 每日 1.5-3 mg(1-2 泵爱斯妥)对应稳态 50-150 pg/mL
- 每日用药会带来细微的日内波动，通常连续涂抹 3-5 天后即可建立稳定的血药稳态。

### 贴片

透皮贴片多采用聚合物基质技术，以近乎恒定的速率将药物释放出来<CitationRef id="hembree-2017" />：

- 首次贴用后，通常在 6-12 小时内即可让血药浓度达到稳态；
- 0.05 mg/天规格对应稳态约 40-60 pg/mL
- 0.1 mg/天规格对应稳态约 80-120 pg/mL
- 在定期更换贴片的过程中，由于持续释放，血液中的药物浓度几乎不会出现明显起伏。

## 使用对比

### 凝胶

**推荐部位**:大腿内侧 · 小腹 · 手臂内侧 · 上背。避开乳房、生殖器、面部。

**操作**:
1. 清洁干燥皮肤(非出汗状态)
2. 挤出泵数,用手掌或纸巾涂匀
3. 等待 5-10 分钟风干,再穿衣
4. 涂抹后洗手(避免转移)

**禁忌时段**:
- 涂后 4 小时内避免淋浴、游泳、桑拿、剧烈出汗
- 涂后 4-6 小时内避免与他人或宠物皮肤直接接触;和婴儿亲密接触需衣物隔离

### 贴片

**推荐部位**:臀部上外 · 小腹 · 下背。轮换避免同一处反复。

**操作**:
1. 清洁干燥皮肤(非润肤霜、出汗状态)
2. 撕下保护膜,按压 10-20 秒
3. 前 24 小时避免剧烈出汗和长时间泡水

**常见问题**:
- **脱落**:剧烈运动、淋浴水温过高可能使粘胶失效。可用医用胶带加固
- **皮肤反应**:10-20% 使用者贴处瘙痒或红斑。每次换位可缓解;持续可考虑改凝胶

## VTE 与代谢安全性

多项大规模临床队列研究均一致表明<CitationRef id="canonico-2018" /><CitationRef id="coleman-2022" />：
- 经皮雌二醇的深静脉血栓（VTE）发生率，基本与未用药人群的基线风险持平；
- 对肝脏合成的性激素结合球蛋白（SHBG）、凝血因子以及 C-反应蛋白（CRP）等指标的影响极小；
- 几乎不会引发胆汁淤积或转氨酶升高等肝脏负担。

**因此，对于 40 岁以上或伴有心血管、血栓高风险因素的跨性别女性，透皮给药（凝胶或贴片）在国际指南中通常被推荐作为首选方案。**

## 剂量选择

### 凝胶

| 品牌 | 规格 | 常用起始 | 常用稳定 |
|---|---|---|---|
| Oestrogel(爱斯妥) | 0.06% 凝胶,1 泵 ≈ 0.75 mg E2 | 2 泵/天 | 3-4 泵/天(分 1-2 次) |
| Estrogel(美国版) | 0.06%,1 泵 = 0.75 mg | 同上 | 同上 |
| Divigel | 包装 0.25/0.5/1 mg | 0.5 mg/天 | 0.75-1.25 mg/天 |

**剂量调整**:每 6-8 周查血调整,每次 ±1 泵或半泵。

### 贴片

| 品牌 | 规格 | 频率 |
|---|---|---|
| Estraderm MX | 0.025 / 0.05 / 0.075 / 0.1 mg/天 | 每 3-4 天 |
| Climara | 0.025 / 0.0375 / 0.05 / 0.075 / 0.1 mg/天 | 每 7 天 |
| Vivelle-Dot | 0.025 / 0.0375 / 0.05 / 0.075 / 0.1 mg/天 | 每 3-4 天 |

**起始**:0.05-0.1 mg/天;**稳定**:多数 0.1 mg/天,部分需 2 片叠加(0.15-0.2 mg/天)。

**剂量调整提示**：贴片的剂量调整灵活性相对较低。虽然你可以通过同时贴两片来叠加剂量，但请不要自行将贴片剪半使用，因为这可能会破坏其基质控释结构，导致药物在短时间内过度释放。

## 中国获取

- **凝胶（爱斯妥/Oestrogel）**：国内已有进口药引进，部分大型综合性医院的妇产科或内分泌科常备。单支价格通常在 120-180 元之间，按常用剂量计算通常可使用 4-6 周。
- **透皮贴片**：目前国内大陆公立医院鲜有正规渠道引进。如果你考虑通过海淘、香港药房等途径获取，建议你务必关注渠道的合规性与运输存储条件，确保用药安全。

**医保与报销**：在大部分地区目前仍属于自费范畴，仅极少数地方医保支持部分门诊统筹报销。

## 如何选择

**在医生指导下，建议优先考虑凝胶的情况**：
- 希望能更精细、灵活地微调每日雌激素用量；
- 曾经对贴片或胶水有过敏、红痒的经历；
- 能够耐受并坚持每日进行涂抹和等待风干的步骤。

**在医生指导下，建议优先考虑贴片的情况**：
- 追求最恒定、平稳的血药浓度，减少体内的生理波动；
- 经常出差、作息不规律，觉得每天涂抹凝胶较为繁琐；
- 皮肤比较耐受，不介意粘贴处偶尔可能出现的红痒。

**当这两种经皮给药方式均不适用时**：
- 如果伴有严重的全身性皮肤病（如广泛性湿疹、银屑病等），可能会影响药物吸收并加重病情；
- 如果你的身体需要极高的雌二醇剂量（例如等效于每日 0.2 mg 以上贴片的浓度），透皮给药的皮肤吸收面积可能受限，此时建议与医生讨论是否换用注射等其他途径。
