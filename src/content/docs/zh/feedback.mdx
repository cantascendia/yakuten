医学内容的准确无误是守护社区健康安全的重要基石。如果你在阅读过程中发现任何笔误、失效信息或具有建设性的改进建议，非常欢迎你随时通过以下渠道向我们反馈。

<WarningBox>
**对于事关用药安全的紧急纠错报告（例如剂量标示笔误、重要禁忌遗漏、或是急症防范说明说明缺失等），编辑团队通常会在 48 小时内优先完成审核与处理更新。**
</WarningBox>

## 内容纠错

如果你在浏览时发现医学专业表述或数据有误，建议你通过 GitHub Issue 向我们提交结构化的纠错报告。

**在报告中，如果能同时提供以下信息，将极大加快我们复核的效率：**
- 发生错误的页面链接（URL）
- 出错位置的具体语句（引用原文）
- 你建议修正后的科学措辞
- 支持该项修正的循证参考文献（如 DOI 编码或权威公开文献链接）

## 纠错审核处理流程

1. **接收登记** —— 你的纠错报告将被系统正式录入审核队列。
2. **循证核实** —— 编辑团队将对你提供的建议修正内容及附带文献进行严格核查。
3. **更正部署** —— 确认无误后，我们将即刻更新受影响的网页，并重新标注内容审核日期。
4. **状态确认** —— 修正发布后，我们会在对应的 GitHub Issue 或反馈渠道回复以确认问题已解决。

| 纠错与反馈类型 | 预计的响应时效 |
|----------------|----------------|
| 事关安全（剂量/禁忌/急症） | 48 小时内 |
| 医学专业数据笔误 | 1 周内 |
| 措辞流畅度或翻译优化 | 1-2 周 |
| 网站交互功能建议 | 视技术开发排期而定 |
