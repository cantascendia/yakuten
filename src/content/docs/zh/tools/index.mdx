## 隐私承诺

- 所有工具**均在前端本地运行**，你的输入数据通常不会发送至任何服务器
- AI 问答助手**不存储你的对话记录**，关闭页面后通常即刻清除
- 「血检手账」功能仅将记录写入**你本地设备的 `localStorage`**，你可以随时一键清空
- 全站分析采用 Vercel Web Analytics 与 Speed Insights（无 Cookie、仅聚合统计、不绑定个人身份），不使用 Google Analytics 或社交媒体追踪器

## 提示

这些工具并不提供诊断。**若遇到任何异常结果，建议你及时带去医院与医生交流**。如果你目前正经历紧急症状，请立即拨打 **120** 或前往最近的急诊室，并仔细阅读 [风险与急症识别](/zh/risks/)。
