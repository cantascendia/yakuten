## 写给回访者

如果你一时间不确定该阅读哪一篇，可以通过以下说明进行快速判别：

- **在接种或进行第一针注射前**，建议你从 [首次注射完整指南](/zh/guides/first-injection/) 开始阅读；
- **如果你已经在使用某种抗雄药物，但面临指标异常或药物难以获取的困境**，请参考 [抗雄切换完整指南](/zh/guides/switch-antiandrogen/)；
- **如果你已经在使用雌二醇，但出于安全或便利考虑希望更换给药途径**，请查阅 [切换 E2 给药途径完整指南](/zh/guides/switch-e2-route/)。

如果你需要更系统的信息，也可以从以下页面起步：

- 还没开始用药 → [用药前：你准备好了吗？](/zh/before-you-start/)
- 不清楚自己在哪个阶段 → [用药路径图](/zh/pathway/)
- 想对比多个药物的参数 → [药物比较器](/zh/tools/drug-comparator/)

## 后续规划

目前我们的指南主要覆盖了三个最常见的决策场景。未来，我们计划根据大家的反馈，逐步补充更多任务型指引（例如：如何解读首次血检报告、如何协调 HRT 与心理咨询的关系，以及长期随访的科学节奏等）。如果你发现自己面临的场景尚未被收录，可以先通过 [AI 问答助手](/zh/tools/ai-assistant/) 获得初步的减害建议，并随时在 [关于本站](/zh/about/) 页面留言，帮助我们持续完善内容。
