หน้านี้อธิบายว่าเนื้อหาทุกชิ้นของ HRT Pharmacopoeia ผ่านการเขียน ตรวจทาน และปรับปรุงมาอย่างไร นี่คือสัญญาที่เราให้ไว้กับผู้อ่าน: **ข้อความที่ยังไม่ผ่านกระบวนการนี้ จะไม่ถูกนำขึ้นเผยแพร่**

## 1. หลักการสำคัญสามข้อ

1. **ไม่มีการอ้างอิง ก็ไม่มีการกล่าวอ้าง**: ข้อกล่าวอ้างทางการแพทย์ทุกข้อต้องมี DOI หรือแนวทางเวชปฏิบัติระดับสากลกำกับอย่างน้อยหนึ่งรายการ หากข้อใดหาแหล่งที่มามายืนยันไม่ได้ จะถูกกำกับด้วย <EvidenceBadge level="X" /> หรือไม่ก็นำออก
2. **ตรวจสอบข้อมูลขนาดยาจากหลายแหล่ง**: ขนาดยาที่ใช้สั่งจ่ายต้องปรากฏในแหล่งอ้างอิงที่น่าเชื่อถือและเป็นอิสระต่อกันอย่างน้อยสองแหล่ง (WPATH SOC 8 · Endocrine Society 2017 · UCSF · EMA และแหล่งในลักษณะเดียวกัน)
3. **เลี่ยงถ้อยคำที่ฟันธงเด็ดขาด**: แทนที่จะใช้คำว่า "ต้อง / เสมอ / ห้ามเด็ดขาด" เราเลือกใช้ "โดยทั่วไป / แนะนำให้ / ในกรณีส่วนใหญ่"

## 2. ขั้นตอนการทำงานทั้งหมด

### 1. การเลือกหัวข้อ
- เลือกหัวข้อจากความต้องการในการค้นหา คำถามจากผู้อ่าน การปรับปรุงแนวทางเวชปฏิบัติ และการแจ้งเตือนด้านความปลอดภัยครั้งสำคัญ (EMA/FDA)
- แต่ละหน้าจะระบุคำถามเฉพาะ 3–7 ข้อที่ต้องตอบให้ได้
- กำหนดกลุ่มผู้อ่านเป้าหมาย (ผู้ป่วย / แพทย์เวชปฏิบัติทั่วไป / คนในครอบครัว) ไว้ตั้งแต่ต้น

### 2. การสืบค้นวรรณกรรม
- ช่องทางหลัก: PubMed, Cochrane, เว็บไซต์แนวทางเวชปฏิบัติอย่างเป็นทางการ, บทปริทัศน์ของ Transfemscience
- สิ่งที่ไม่นำมาใช้: โพสต์ในฟอรัมแบบไม่ระบุตัวตน เว็บไซต์เชิงพาณิชย์ บล็อกที่ไม่ผ่านการตรวจทานโดยผู้ทรงคุณวุฒิ
- ข้อกล่าวอ้างสำคัญทุกข้อมีการบันทึกแหล่งอ้างอิงต้นฉบับไว้ (ให้ความสำคัญกับ DOI เป็นอันดับแรก หากไม่มีจะบันทึกข้อมูลการตีพิมพ์ในวารสารแทน)

### 3. การจัดระดับหลักฐาน
จัดระดับตามความหนักแน่นของรูปแบบการศึกษา:

| ระดับ | ความหมาย | ตัวอย่างหลักฐาน |
|---|---|---|
| <EvidenceBadge level="A" /> | แข็งแรง | RCT หลายฉบับ การทบทวนอย่างเป็นระบบ / การวิเคราะห์อภิมาน คำแนะนำที่ระบุชัดเจนในแนวทางเวชปฏิบัติระดับสากล |
| <EvidenceBadge level="B" /> | ปานกลาง | RCT ฉบับเดียว การศึกษาแบบ prospective cohort หลายฉบับ |
| <EvidenceBadge level="C" /> | อ่อน | รายงานผู้ป่วย การศึกษาแบบย้อนหลัง ความเห็นของผู้เชี่ยวชาญ |
| <EvidenceBadge level="X" /> | ไม่มี | ความเชื่อในชุมชน ประสบการณ์ส่วนตัว การอนุมาน |

### 4. การร่างเนื้อหา
- ใช้คอมโพเนนต์ร่วมกัน: `<DrugInfoBox>`, `<DoseTable>`, `<CitationRef>`, `<WarningBox>`, `<EmergencyBanner>` เป็นต้น
- Frontmatter บันทึก `evidenceLevel`, `lastReviewed`, และ `references` (บังคับใช้ผ่าน CI)
- ตารางขนาดยาจะตรวจสอบขีดจำกัดสูงสุดและการใช้ร่วมที่เป็นข้อห้ามโดยอัตโนมัติ

### 5. การตรวจทานไขว้สองคน
- เมื่อผู้เขียนร่างเสร็จ → บรรณาธิการคนที่สองจะตรวจสอบ `<CitationRef>` ทุกรายการเทียบกับแหล่งต้นฉบับอย่างเป็นอิสระ
- หากพบความไม่ตรงกันหรือการตีความที่เกินเลย → ส่งคืนเพื่อแก้ไข
- หากแหล่งต้นฉบับถูกเพิกถอนหรือมีการแก้ไข → ค้นหาและแทนที่ทั่วทั้งเว็บไซต์

### 6. การทบทวนโดยที่ปรึกษาทางการแพทย์
- มอบหมายที่ปรึกษาด้านต่อมไร้ท่อ / จิตเวช / กฎหมาย ตามแต่ละหัวข้อ
- บันทึกการทบทวน รวมถึงความเห็นแย้งและข้อตัดสินสุดท้าย จะถูกจัดเก็บเป็นเอกสาร
- หากไม่สามารถติดต่อผู้ตรวจทานที่มีคุณสมบัติได้ หัวข้อนั้นจะไม่ถูกเผยแพร่

### 7. การเผยแพร่และการตรวจสอบคุณภาพด้านการเข้าถึง
- `npm run astro check` + Lighthouse (SEO ≥ 95 / A11y ≥ 95)
- ตรวจสอบความเปรียบต่างของสี การเข้าถึงด้วยแป้นพิมพ์ และความหมายเชิงโครงสร้างสำหรับโปรแกรมอ่านหน้าจอ
- ยืนยันจุดเปลี่ยนการแสดงผลบนมือถือ (breakpoints) และการสำรองสำหรับ `prefers-reduced-motion`

### 8. การทบทวนต่อเนื่อง
- ทบทวนซ้ำทุก **12 เดือน** เป็นค่าเริ่มต้น พร้อมปรับค่า `lastReviewed` ให้เป็นปัจจุบัน
- หน้าที่มีความเสี่ยงสูง (ความเสี่ยง เส้นแดงของขนาดยา ภาวะฉุกเฉิน) จะทบทวนซ้ำทุก **6 เดือน**
- เมื่อแนวทางเวชปฏิบัติมีการเปลี่ยนแปลงครั้งใหญ่ → อัปเดตเพิ่มเติมภายใน 48 ชั่วโมง

## 3. การแก้ไขข้อผิดพลาด

เมื่อผู้อ่านพบข้อผิดพลาดเชิงข้อเท็จจริง การอ้างอิงที่คลาดเคลื่อน หรือเนื้อหาที่ล้าสมัย:

1. ส่งรายงานผ่าน[แบบฟอร์มแสดงความคิดเห็น](https://wj.qq.com/s2/16576000/5fe5/) หรือ GitHub Issue
2. เราจะตอบกลับครั้งแรกภายใน 72 ชั่วโมง
3. เมื่อยืนยันแล้วว่าเป็นข้อผิดพลาดเชิงข้อเท็จจริง จะมีการเพิ่ม**ประกาศแจ้งข้อผิดพลาด (erratum)** ไว้ที่ส่วนบนของหน้า และประวัติเวอร์ชันจะบันทึกข้อผิดพลาดเดิมพร้อมวันที่แก้ไข
4. การแก้ไขที่สำคัญจะถูกส่งต่อไปยังผู้ติดตามทางอีเมล / RSS / Telegram

## 4. คำแถลงเรื่องผลประโยชน์ทับซ้อน

- เว็บไซต์นี้ไม่มีผู้สนับสนุนเชิงพาณิชย์ ไม่มีการโฆษณายา และไม่มีค่าคอมมิชชันจากการซื้อขาย
- ค่าใช้จ่ายในการดำเนินงานมาจากกระเป๋าของอาสาสมัครเอง และเรารับเงินบริจาคจากชุมชนโอเพนซอร์ส
- บรรณาธิการและที่ปรึกษาทางการแพทย์ลงนามในการเปิดเผยผลประโยชน์ทับซ้อน ยาที่มีความสัมพันธ์ด้านการสั่งจ่ายที่ยังดำเนินอยู่จะไม่ถูกตรวจทานโดยผู้ที่มีผลประโยชน์ทับซ้อนนั้นอย่างเป็นอิสระ

<WarningBox>
เว็บไซต์นี้นำเสนอข้อมูลอ้างอิงเชิงประจักษ์และ **ไม่ถือเป็นคำแนะนำทางการแพทย์** โปรดปรึกษาบุคลากรทางการแพทย์ที่มีคุณสมบัติก่อนเปลี่ยนแปลงการใช้ยาของคุณ และรีบเข้ารับการรักษาฉุกเฉินทันทีหากมีอาการเฉียบพลัน
</WarningBox>
