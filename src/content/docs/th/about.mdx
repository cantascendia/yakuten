## พันธกิจ

**อิงหลักฐานเชิงประจักษ์ · ลดอันตราย · นำทางคุณสู่การดูแลทางการแพทย์**

HRT Yakuten เป็นเว็บไซต์ข้อมูลด้านมาตรฐานความปลอดภัยขั้นพื้นฐานสำหรับหญิงข้ามเพศในชุมชนผู้ใช้ภาษาจีนที่ใช้ HRT (ฮอร์โมนบำบัดเพื่อยืนยันเพศสภาพ) เป้าหมายของเราไม่ใช่การทำหน้าที่แทนแพทย์ แต่เพื่อช่วยเหลือผู้ที่กำลังใช้ — หรือกำลังจะเริ่ม — ฮอร์โมนบำบัด ให้สามารถ:

- **เข้าใจผลตรวจเลือดของตนเอง** และรู้ว่าค่าผิดปกติแบบใดที่ควรไปพบแพทย์
- **เรียนรู้ความเสี่ยงที่แท้จริงของยา** แทนที่จะพึ่งพาคำบอกเล่าในชุมชนและประสบการณ์ส่วนตัวที่ยังไม่ได้รับการตรวจสอบ
- **สังเกตสัญญาณเตือนภาวะฉุกเฉิน** (DVT ภาวะลิ่มเลือดอุดตันหลอดเลือดดำส่วนลึก, ตับเสียหาย, เนื้องอกเยื่อหุ้มสมอง) และตัดสินใจได้อย่างถูกต้องในจังหวะวิกฤต
- **ค้นหาแหล่งบริการทางการแพทย์ที่เป็นมิตรต่อคนข้ามเพศ** และก้าวจากการทำเอง (DIY) ไปสู่การดูแลทางการแพทย์ภายใต้การกำกับดูแล

### เว็บไซต์นี้ไม่ใช่อะไร

- ❌ ไม่ใช่สารานุกรมหรือตำราแพทย์
- ❌ ไม่ใช่ฟอรัม ชุมชน หรือแพลตฟอร์มสังคมออนไลน์
- ❌ ไม่ใช่ช่องทางจัดซื้อยาหรือเว็บไซต์แนะนำร้านขายยา
- ❌ ไม่ให้คำแนะนำเรื่องขนาดยาแบบเฉพาะบุคคล ("คุณควรใช้ X mg")

## แหล่งที่มาของเนื้อหา

เนื้อหาทางการแพทย์ทั้งหมดบนเว็บไซต์นี้อ้างอิงจากแนวทางเวชปฏิบัติระดับสากลและวรรณกรรมที่ผ่านการทบทวนโดยผู้เชี่ยวชาญ (peer-reviewed) ดังต่อไปนี้:

| แหล่งที่มา | คำอธิบาย |
|--------|-------------|
| **Endocrine Society 2017** | *Endocrine Treatment of Gender-Dysphoric/Gender-Incongruent Persons* — แนวทางเวชปฏิบัติ |
| **WPATH SOC 8 (2022)** | *Standards of Care for the Health of Transgender and Gender Diverse People*, ฉบับที่ 8 |
| **UCSF Transgender Care** | University of California, San Francisco — แนวทางการดูแลคนข้ามเพศ |
| **EMA (2020)** | ข้อจำกัดและการประเมินความปลอดภัยของ CPA โดย European Medicines Agency (สำนักงานยาแห่งยุโรป) |
| **PubMed / PMC** | งานวิจัยต้นฉบับที่ผ่านการทบทวนโดยผู้เชี่ยวชาญ (แต่ละการอ้างอิงมี DOI กำกับ) |

ตัวเลขยกกำลังที่อยู่ถัดจากคำแนะนำทางการแพทย์แต่ละข้อ (เช่น <sup>[1]</sup>) เชื่อมโยงไปยังเอกสารอ้างอิงเฉพาะนั้น **ไม่มีการอ้างอิง = ไม่มีเนื้อหา** — นี่คือกฎเหล็กของเว็บไซต์นี้

## กระบวนการทบทวนเนื้อหา

| ขั้นตอน | มาตรฐาน |
|------|----------|
| **ข้อกำหนดด้านการอ้างอิง** | คำแนะนำทางคลินิกทุกข้อต้องสืบย้อนกลับไปยังงานวิจัยที่ผ่านการทบทวนโดยผู้เชี่ยวชาญหรือแนวทางระดับสากลอย่างน้อยหนึ่งฉบับ |
| **การตรวจสอบไขว้** | ช่วงขนาดยาต้องได้รับการตรวจสอบไขว้กับแหล่งข้อมูลอิสระ ≥2 แหล่ง (เช่น WPATH + Endocrine Society + UCSF) |
| **การจัดระดับหลักฐาน** | แต่ละหน้าจะระบุระดับหลักฐาน: A (RCT หลายฉบับ/Meta-analysis), B (RCT/การศึกษาแบบ cohort เดี่ยว), C (รายงานผู้ป่วย/ความเห็นผู้เชี่ยวชาญ), X (ไม่มีหลักฐาน) |
| **วันที่ทบทวน** | แต่ละหน้าจะแสดงวันที่ทบทวนล่าสุดไว้ที่ด้านล่าง |
| **รอบการปรับปรุง** | เนื้อหาจะได้รับการทบทวนทุกไตรมาสเพื่อความเป็นปัจจุบัน และปรับปรุงตามวรรณกรรมที่เผยแพร่ใหม่ |

<WarningBox title="ข้อจำกัดของเนื้อหา">
ปัจจุบันเว็บไซต์นี้ดูแลโดยบุคคลคนเดียวและยังไม่ได้ผ่านการทบทวนโดยผู้เชี่ยวชาญ (peer review) อย่างเป็นทางการจากบรรณาธิการทางการแพทย์มืออาชีพ เราพยายามอย่างเต็มที่เพื่อให้มั่นใจในความถูกต้อง แต่ก็อาจมีข้อผิดพลาดและตกหล่นได้ หากคุณพบความไม่ถูกต้องใด ๆ โปรดส่ง Issue บน GitHub
</WarningBox>

## ความเป็นส่วนตัว

**เว็บไซต์นี้ไม่เก็บรวบรวมหรือจัดเก็บข้อมูลส่วนบุคคลใด ๆ**

| ประเภท | มาตรการ |
|----------|---------|
| **เครื่องมือตรวจผลเลือด** | คำนวณด้วย JavaScript ฝั่งหน้าเว็บล้วน ๆ — ข้อมูลที่คุณป้อนจะไม่ออกจากเบราว์เซอร์ของคุณ และไม่ถูกส่งไปยังเซิร์ฟเวอร์ใด ๆ |
| **ถาม-ตอบด้วย AI** | บทสนทนาจะถูกประมวลผลแบบเรียลไทม์ผ่าน Edge Functions — ไม่มีการจัดเก็บ บันทึก หรือนำไปใช้ฝึกโมเดล |
| **การวิเคราะห์ข้อมูล** | Vercel Web Analytics และ Speed Insights — เก็บเฉพาะยอดเข้าชมหน้าและตัวชี้วัดประสิทธิภาพแบบรวม ไม่ใช้คุกกี้ ไม่จัดเก็บตัวระบุตัวตนส่วนบุคคล และไม่มีการติดตามข้ามเว็บไซต์ |
| **การติดตาม** | ไม่มี Google Analytics ไม่มีตัวติดตามของโซเชียลมีเดียหรือโฆษณาที่ฝังมา — นอกเหนือจากการวิเคราะห์แบบรวมของ Vercel ข้างต้น |
| **คุกกี้** | ใช้เฉพาะเพื่อจดจำการตั้งค่าธีม (โหมดมืด/สว่าง) เท่านั้น ไม่ใช้เพื่อการติดตาม |
| **โฆษณา** | ไม่มี และจะไม่มีตลอดไป |

## ข้อจำกัดความรับผิด

เนื้อหาบนเว็บไซต์นี้มีไว้**เพื่อการศึกษาและให้ข้อมูลเท่านั้น** และไม่ถือเป็นคำแนะนำทางการแพทย์

- เว็บไซต์นี้ไม่สามารถทดแทนการวินิจฉัยและการรักษาแบบพบหน้าโดยแพทย์ผู้มีคุณสมบัติได้
- การใช้ การปรับ และการหยุดยา ควรดำเนินการภายใต้การกำกับดูแลของบุคลากรทางการแพทย์ผู้มีคุณสมบัติ
- หากคุณมีอาการฉุกเฉินใด ๆ (ขาบวม/ปวดข้างเดียว, เจ็บหน้าอกเฉียบพลัน, ตัวเหลืองตาเหลือง ฯลฯ) ให้หยุดยาทันทีและไปยังห้องฉุกเฉินที่ใกล้ที่สุด
- เว็บไซต์นี้ไม่รับผิดชอบต่อผลกระทบทางการแพทย์ใด ๆ ที่เกิดจากการนำเนื้อหาไปใช้

**การใช้ยาด้วยตนเอง (DIY) มีความเสี่ยงที่แท้จริง** เว็บไซต์นี้มุ่งช่วยให้คุณใช้ยาได้อย่างปลอดภัยมากขึ้น แต่แนวทางที่ปลอดภัยที่สุดเสมอคือการทำ HRT ภายใต้การกำกับดูแลของแพทย์
