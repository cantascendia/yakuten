## พันธกิจ

**อิงหลักฐานเชิงประจักษ์ · ลดอันตราย · นำทางคุณสู่การดูแลทางการแพทย์**

HRT Yakuten เป็นเว็บไซต์ที่รวบรวมข้อมูลมาตรฐานความปลอดภัยขั้นพื้นฐานสำหรับหญิงข้ามเพศในชุมชนผู้ใช้ภาษาจีนที่ใช้ HRT (ฮอร์โมนบำบัดเพื่อยืนยันเพศสภาพ) เราไม่ได้ตั้งใจจะมาทำหน้าที่แทนแพทย์ แต่อยากเป็นเพื่อนเคียงข้างคุณที่กำลังใช้ฮอร์โมนอยู่ — หรือกำลังจะเริ่ม — เพื่อให้คุณ:

- **อ่านผลตรวจเลือดของตัวเองได้เข้าใจ** และรู้ว่าค่าผิดปกติแบบไหนที่ถึงเวลาต้องไปพบแพทย์
- **เข้าใจความเสี่ยงที่แท้จริงของยา** แทนที่จะเชื่อตามคำบอกเล่าในชุมชนหรือประสบการณ์ส่วนตัวที่ยังไม่ได้รับการตรวจสอบ
- **สังเกตสัญญาณเตือนภาวะฉุกเฉินได้ทัน** (DVT ภาวะลิ่มเลือดอุดตันหลอดเลือดดำส่วนลึก, ตับเสียหาย, เนื้องอกเยื่อหุ้มสมอง) เพื่อตัดสินใจได้อย่างถูกต้องในจังหวะวิกฤต
- **ค้นหาแหล่งบริการทางการแพทย์ที่เป็นมิตรต่อคนข้ามเพศ** เพื่อก้าวจากการทำเอง (DIY) ไปสู่การดูแลทางการแพทย์ภายใต้การกำกับดูแลของแพทย์

### เว็บไซต์นี้ไม่ใช่อะไร

- ❌ ไม่ใช่สารานุกรมหรือตำราแพทย์
- ❌ ไม่ใช่ฟอรัม ชุมชน หรือแพลตฟอร์มสังคมออนไลน์
- ❌ ไม่ใช่ช่องทางจัดซื้อยาหรือเว็บไซต์แนะนำร้านขายยา
- ❌ ไม่ให้คำแนะนำเรื่องขนาดยาแบบเฉพาะบุคคล ("คุณควรใช้ X mg")

## แหล่งที่มาของเนื้อหา

เนื้อหาทางการแพทย์ทั้งหมดบนเว็บไซต์นี้อ้างอิงจากแนวทางเวชปฏิบัติระดับสากลและงานวิจัยที่ผ่านการทบทวนโดยผู้เชี่ยวชาญ (peer-reviewed) ดังต่อไปนี้:

| แหล่งที่มา | คำอธิบาย |
|--------|-------------|
| **Endocrine Society 2017** | *Endocrine Treatment of Gender-Dysphoric/Gender-Incongruent Persons* — แนวทางเวชปฏิบัติ |
| **WPATH SOC 8 (2022)** | *Standards of Care for the Health of Transgender and Gender Diverse People*, ฉบับที่ 8 |
| **UCSF Transgender Care** | University of California, San Francisco — แนวทางการดูแลคนข้ามเพศ |
| **EMA (2020)** | ข้อจำกัดและการประเมินความปลอดภัยของ CPA โดย European Medicines Agency (สำนักงานยาแห่งยุโรป) |
| **PubMed / PMC** | งานวิจัยต้นฉบับที่ผ่านการทบทวนโดยผู้เชี่ยวชาญ (แต่ละการอ้างอิงมี DOI กำกับ) |

ตัวเลขยกกำลังที่อยู่ถัดจากคำแนะนำทางการแพทย์แต่ละข้อ (เช่น <sup>[1]</sup>) จะเชื่อมโยงไปยังเอกสารอ้างอิงนั้นโดยตรง **ไม่มีการอ้างอิง = ไม่มีเนื้อหา** — นี่คือกฎเหล็กของเว็บไซต์นี้

## กระบวนการทบทวนเนื้อหา

| ขั้นตอน | มาตรฐาน |
|------|----------|
| **ข้อกำหนดด้านการอ้างอิง** | คำแนะนำทางคลินิกทุกข้อต้องสืบย้อนกลับไปยังงานวิจัยที่ผ่านการทบทวนโดยผู้เชี่ยวชาญหรือแนวทางระดับสากลได้อย่างน้อยหนึ่งฉบับ |
| **การตรวจสอบไขว้** | ช่วงขนาดยาต้องผ่านการตรวจสอบไขว้กับแหล่งข้อมูลอิสระ ≥2 แหล่ง (เช่น WPATH + Endocrine Society + UCSF) |
| **การจัดระดับหลักฐาน** | แต่ละหน้าจะระบุระดับหลักฐานกำกับไว้: A (RCT หลายฉบับ/Meta-analysis), B (RCT/การศึกษาแบบ cohort เดี่ยว), C (รายงานผู้ป่วย/ความเห็นผู้เชี่ยวชาญ), X (ไม่มีหลักฐาน) |
| **วันที่ทบทวน** | แต่ละหน้าจะแสดงวันที่ทบทวนล่าสุดไว้ที่ด้านล่าง |
| **รอบการปรับปรุง** | เนื้อหาจะได้รับการทบทวนทุกไตรมาสเพื่อให้ทันสมัยอยู่เสมอ และปรับปรุงตามวรรณกรรมที่เผยแพร่ใหม่ |

<WarningBox title="ข้อจำกัดของเนื้อหา">
ปัจจุบันเว็บไซต์นี้ดูแลโดยบุคคลคนเดียว และยังไม่ได้ผ่านการทบทวนโดยผู้เชี่ยวชาญ (peer review) อย่างเป็นทางการจากบรรณาธิการทางการแพทย์มืออาชีพ เราพยายามอย่างเต็มที่เพื่อให้มั่นใจในความถูกต้อง แต่ก็อาจมีข้อผิดพลาดและตกหล่นได้ หากคุณพบความไม่ถูกต้องใด ๆ โปรดส่ง Issue บน GitHub
</WarningBox>

## ความเป็นส่วนตัว

**ไม่ต้องสมัครบัญชี ไม่มีโฆษณา และไม่ขายข้อมูล ต่อไปนี้คือคำอธิบายตรงไปตรงมาว่าเว็บไซต์นี้ใช้บริการภายนอกอะไรบ้าง และข้อมูลของคุณไปอยู่ที่ใด**

| ประเภท | สิ่งที่เกิดขึ้น |
|----------|---------|
| **สถิติการเข้าชม** | เราใช้ Google Analytics 4 และ Vercel Web Analytics / Speed Insights เพื่อนับยอดเข้าชมหน้า เหตุการณ์ และตัวชี้วัดประสิทธิภาพแบบรวม Google Analytics จะตั้งคุกกี้ในเบราว์เซอร์ของคุณ (เช่น `_ga`) คุณสามารถบล็อกได้ผ่านการตั้งค่าเบราว์เซอร์หรือโปรแกรมบล็อกโฆษณา และเว็บไซต์จะยังใช้งานได้ตามปกติ |
| **สิ่งที่ไม่ส่งให้บริการวิเคราะห์** | ข้อมูลสุขภาพ สิ่งที่คุณพิมพ์ในเครื่องมือ บทสนทนากับ AI และบันทึกผลเลือด จะไม่ถูกส่งไปยังบริการวิเคราะห์ใด ๆ |
| **ถาม-ตอบด้วย AI** | คำตอบสร้างโดยผู้ให้บริการ AI ภายนอก (ปัจจุบันคือ Google Gemini และ OpenAI) คำถามของคุณจะถูกส่งต่อผ่านเซิร์ฟเวอร์ของเราไปยังผู้ให้บริการเหล่านี้ เราไม่จัดเก็บหรือบันทึกเนื้อหาบทสนทนา แต่ข้อกำหนดของผู้ให้บริการอาจอนุญาตให้นำเนื้อหาที่ส่งไปใช้ปรับปรุงบริการของตน จึงไม่ควรใส่ชื่อ เบอร์โทรศัพท์ เลขบัตรประชาชน หรือข้อมูลใดที่ระบุตัวคุณได้ |
| **ข้อมูลในเครื่อง** | บันทึกสมุดผลเลือด ประวัติแชต AI (เฉพาะเมื่อคุณเปิด "บันทึกประวัติการสนทนาในอุปกรณ์นี้") และการตั้งค่าหน้าจอ (เช่น ธีม) จะอยู่ใน localStorage ของเบราว์เซอร์คุณเท่านั้นและไม่ถูกอัปโหลด คุณลบได้ด้วยปุ่มล้างข้อมูลในเครื่องมือ หรือโดยล้างข้อมูลเว็บไซต์นี้ในเบราว์เซอร์ |
| **เครื่องมืออื่น ๆ** | เครื่องมือตรวจผลเลือด ตัวจำลองขนาดยา เครื่องคำนวณการฉีด และเครื่องมืออื่น ๆ คำนวณทั้งหมดในเบราว์เซอร์ของคุณ ข้อมูลที่คุณป้อนจะไม่ถูกส่งไปยังเซิร์ฟเวอร์ใด ๆ |
| **การติดตามและโฆษณา** | ไม่มีพิกเซลติดตามของโฆษณาหรือโซเชียลมีเดีย ไม่มีโฆษณา และจะไม่มีตลอดไป |

## ข้อจำกัดความรับผิด

เนื้อหาบนเว็บไซต์นี้มีไว้**เพื่อการศึกษาและให้ข้อมูลเท่านั้น** และไม่ถือเป็นคำแนะนำทางการแพทย์

- เว็บไซต์นี้ไม่สามารถทดแทนการวินิจฉัยและการรักษาแบบพบหน้าโดยแพทย์ผู้มีคุณสมบัติได้
- การใช้ การปรับ และการหยุดยา ควรดำเนินการภายใต้การกำกับดูแลของบุคลากรทางการแพทย์ผู้มีคุณสมบัติ
- หากคุณมีอาการฉุกเฉินใด ๆ (ขาบวม/ปวดข้างเดียว, เจ็บหน้าอกเฉียบพลัน, ตัวเหลืองตาเหลือง ฯลฯ) ให้หยุดยาทันทีและไปยังห้องฉุกเฉินที่ใกล้ที่สุด
- เว็บไซต์นี้ไม่รับผิดชอบต่อผลกระทบทางการแพทย์ใด ๆ ที่เกิดจากการนำเนื้อหาไปใช้

**การใช้ยาด้วยตนเอง (DIY) มีความเสี่ยงที่แท้จริง** เว็บไซต์นี้มุ่งช่วยให้คุณใช้ยาได้อย่างปลอดภัยมากขึ้น แต่แนวทางที่ปลอดภัยที่สุดเสมอคือการทำ HRT ภายใต้การกำกับดูแลของแพทย์
