## ข้อห้ามเด็ดขาด

HRT Pharmacopoeia จะไม่เผยแพร่สิ่งต่อไปนี้โดยเด็ดขาด:

<DangerBox>
- คำแนะนำการสั่งจ่ายยาแบบเฉพาะบุคคล ("คุณควรใช้ X มก.")
- ลิงก์ซื้อยา ตัวแทนจำหน่าย หรือคิวอาร์โค้ดแนะนำ/รับค่าคอมมิชชัน
- ถ้อยคำที่ลดทอนการตระหนักถึงภาวะฉุกเฉินทางการแพทย์ (DVT, ภาวะตับเป็นพิษ, เนื้องอกเยื่อหุ้มสมอง ฯลฯ)
- ข้อกล่าวอ้างทางการแพทย์ที่ไม่มี DOI หรือแหล่งอ้างอิง
- สคริปต์ติดตามของบุคคลที่สาม หรือการจัดเก็บข้อมูลสุขภาพของผู้ใช้
- การตั้งค่าที่หลีกเลี่ยงคำปฏิเสธความรับผิดของ AI หรือคำเตือนด้านความปลอดภัย
</DangerBox>

## ภาษาและน้ำเสียง

- **หลีกเลี่ยงคำที่ฟันธงเด็ดขาด**: เลือกใช้ "เราแนะนำ / โดยทั่วไป / ในกรณีส่วนใหญ่" แทน "ต้อง / เสมอ / ห้ามเด็ดขาด"
- **สื่อสารกับผู้อ่านโดยตรง**: เขียนว่า "คุณสามารถเลือก A หรือ B" แทนที่จะเป็น "ผู้ป่วยควรเลือก A"
- **ระบุความไม่แน่นอนอย่างตรงไปตรงมา**: ข้อสรุปที่อยู่ในระดับหลักฐาน B/C/X ต้องกำกับด้วยข้อความว่า "ข้อมูลยังมีจำกัด" หรือ "ความเห็นของผู้เชี่ยวชาญ"
- **ลดการตีตรา**: ใช้ภาษาที่เคารพและยืนยันตัวตนของชุมชน และหลีกเลี่ยงคำที่ล้าสมัยหรือเป็นศัพท์ทางคลินิกจนเกินไป

## การอ้างอิงและลิขสิทธิ์

- ทุกข้อกล่าวอ้างทางการแพทย์มีแหล่งอ้างอิงผ่านคอมโพเนนต์ `CitationRef` (ID เชื่อมโยงกับรายการใน `src/data/references.json`)
- เราให้ความสำคัญกับ DOI เป็นอันดับแรก ในกรณีที่ไม่มี DOI จะอ้างอิงข้อมูลการตีพิมพ์ในวารสารพร้อมกับ URL ที่ถาวร
- ภาพและแผนภาพเป็นงานต้นฉบับหรือมาจากงานภายใต้ Creative Commons / สาธารณสมบัติ การนำมาใช้ซ้ำจะระบุเครดิตไว้
- เนื้อหาต้นฉบับของเว็บไซต์เผยแพร่ภายใต้ CC BY-SA 4.0 ส่วนโค้ดอยู่ภายใต้ข้อกำหนด LICENSE ของรีพอซิทอรี

## การแก้ไขข้อผิดพลาด

ผู้อ่านสามารถส่งรายงานได้ผ่าน[แบบฟอร์มแสดงความคิดเห็น](https://wj.qq.com/s2/16576000/5fe5/) หรือ [GitHub Issues](https://github.com/cantascendia/yakuten/issues):

| ประเภท | เวลาตอบกลับ | การจัดการ |
|---|---|---|
| ข้อผิดพลาดเชิงข้อเท็จจริง | ตอบกลับครั้งแรกภายใน 72 ชั่วโมง | **ประกาศแจ้งข้อผิดพลาด (erratum)** ที่ส่วนบนของหน้า + บันทึกการเปลี่ยนแปลง |
| การอ้างอิงคลาดเคลื่อน | 72 ชั่วโมง | เปลี่ยนแหล่งอ้างอิงและเผยแพร่บันทึกการแก้ไขต่อสาธารณะ |
| ข้อมูลล้าสมัย | 7 วัน | อัปเดตเพิ่มเติม + ปรับค่า `lastReviewed` ให้เป็นปัจจุบัน |
| คำแนะนำที่เป็นอันตราย | นำออกฉุกเฉินภายใน 24 ชั่วโมง | แก้ไขหรือพักการเผยแพร่ไว้ก่อนระหว่างรอการตรวจสอบ |

การแก้ไขที่สำคัญจะถูกเผยแพร่ต่อไปยัง:

- ประวัติเวอร์ชันที่ `/th/appendix-references/`
- ผู้ติดตามทาง RSS / Telegram / อีเมล

## การร้องเรียนและการอุทธรณ์

- **ร้องเรียนเกี่ยวกับเนื้อหา**: [แบบฟอร์มแสดงความคิดเห็น](https://wj.qq.com/s2/16576000/5fe5/)
- **ด้านกฎหมาย / ลิขสิทธิ์**: เปิด GitHub Issue พร้อมป้ายกำกับ `legal` หรือติดต่อผู้ดูแลรีพอซิทอรี
- **ความเป็นส่วนตัว**: เว็บไซต์นี้ไม่เก็บข้อมูลที่ระบุตัวบุคคลได้ หากมีการรายงานการรั่วไหลของข้อมูลส่วนบุคคลจะได้รับการจัดการภายใน 24 ชั่วโมง

## การเปิดเผยผลประโยชน์ทับซ้อน

- **ไม่มีผู้สนับสนุนเชิงพาณิชย์ ไม่มีการโฆษณายา ไม่มีค่าคอมมิชชันจากการซื้อขาย**
- ค่าใช้จ่ายในการดำเนินงานมาจากการอาสาสมัครและเงินบริจาคจากชุมชนโอเพนซอร์ส
- บรรณาธิการและที่ปรึกษาทางการแพทย์ลงนามในการเปิดเผยผลประโยชน์ทับซ้อน หัวข้อที่มีความสัมพันธ์ด้านการสั่งจ่ายยาหรือเชิงพาณิชย์โดยตรงจะถูกถอนตัวออกจากการพิจารณา
- ลิงก์ภายนอกไม่มีรหัสระบุพันธมิตร (affiliate) ใด ๆ และแสดงเฉพาะแหล่งข้อมูลโรงพยาบาลและสายด่วนที่ผ่านการตรวจสอบจากชุมชนเท่านั้น

## รอบการทบทวน

| ประเภทหน้า | ช่วงเวลาทบทวนตามค่าเริ่มต้น |
|---|---|
| การรู้จักภาวะฉุกเฉิน เส้นแดงของขนาดยา คำเตือนถึงอันตราย | **6 เดือน** |
| เอกสารข้อมูลยา (monograph) และคู่มือ | **12 เดือน** |
| เครื่องมือ นโยบาย ระเบียบวิธี | **12 เดือน** |
| บทความบล็อก | ตรวจสอบยืนยันหนึ่งครั้งเมื่อครบ 12 เดือนหลังเผยแพร่ |

การเปลี่ยนแปลงแนวทางเวชปฏิบัติครั้งใหญ่ (การแจ้งเตือนด้านความปลอดภัยจาก EMA/FDA, ฉบับใหม่ของ WPATH / Endocrine Society) จะกระตุ้นให้เกิด**การอัปเดตเพิ่มเติมภายใน 48 ชั่วโมง**

<WarningBox>
หน้านี้คือคำมั่นสัญญาต่อสาธารณะในการกำกับดูแลตนเองด้านบรรณาธิการ **หากคุณพบว่าเราละเมิดข้อใดข้อหนึ่งข้างต้น โปรดท้วงติงต่อสาธารณะ** — ความรับผิดชอบที่ตรวจสอบได้นี้คือหนทางเดียวที่ทำให้เรารักษาความไว้วางใจของผู้อ่านไว้ได้

</WarningBox>
