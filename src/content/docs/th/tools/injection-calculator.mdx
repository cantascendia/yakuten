ใช้เครื่องมือนี้เพื่อช่วยประมาณความเข้มข้นและแปลงปริมาตรของเอสตราไดออล (E2) ชนิดฉีด ตัวเลขที่ได้เป็นเพียงค่าอ้างอิงประกอบการพิจารณาเท่านั้น ไม่ใช่คำแนะนำการใช้ยาเฉพาะบุคคล

:::caution[เรื่องสำคัญ]
ก่อนนำผลการคำนวณไปใช้จริงทุกครั้ง ให้ตรวจสอบความเข้มข้นที่ระบุบนขวดยา หน่วยวัด และวิธีการให้ยาให้ถูกต้องเสมอ
:::

:::note[สถานะการแปลภาษา]
หน้าจอของเครื่องมือแบบโต้ตอบยังอยู่ระหว่างการแปลเป็นภาษาไทย ป้ายกำกับและข้อความประกอบบางส่วนอาจยังเป็นภาษาจีนอยู่ชั่วคราว
:::
