ใช้เครื่องมือนี้เพื่อตรวจสอบค่าตรวจเลือดทั่วไปสำหรับการใช้ HRT ด้วยภาพอย่างรวดเร็ว เช่น เอสตราไดออล (estradiol) เทสโทสเตอโรน (testosterone) โพรแลกติน (prolactin) เอนไซม์ตับ โพแทสเซียม ฮีโมโกลบิน และดี-ไดเมอร์ (D-dimer)

:::caution[ข้อควรทราบ]
เครื่องมือนี้มีไว้เพื่อให้ความรู้เท่านั้น หากผลตรวจผิดปกติ มีอาการรุนแรง หรือมีข้อกังวลเร่งด่วน ควรได้รับการประเมินจากแพทย์ผู้เชี่ยวชาญเสมอ
:::

:::note[สถานะการแปลภาษา]
ส่วนต่อประสานของเครื่องมือแบบโต้ตอบนี้ยังอยู่ระหว่างการแปลภาษา ป้ายกำกับปุ่มควบคุมและข้อความเตือนบางส่วนอาจยังคงเป็นภาษาจีนชั่วคราว
:::
