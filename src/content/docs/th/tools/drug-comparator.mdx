## การเปรียบเทียบยา

เลือกยามา 2-3 ชนิด แล้วดูพารามิเตอร์สำคัญของแต่ละตัววางเทียบกันได้ในพริบตา

**เครื่องมือนี้จะช่วยให้คุณเห็นภาพชัดขึ้นในเรื่อง:**

- ความเสี่ยง VTE (ภาวะลิ่มเลือดอุดตันในหลอดเลือดดำ) ที่ต่างกันไปตามวิธีให้เอสโตรเจน (ชนิดกิน เทียบกับชนิดแปะ/ทาผ่านผิวหนัง เทียบกับชนิดฉีด)
- สิ่งที่ต้องเฝ้าติดตามและข้อห้ามใช้ของยาต้านแอนโดรเจนแต่ละตัว
- ระดับหลักฐานและช่วงขนาดยาของยาแต่ละชนิด

## อ่านผลที่ได้อย่างไร

- **ความเสี่ยง VTE (RR)**: ค่าความเสี่ยงสัมพัทธ์ (relative risk) โดยถือ RR=1.0 เป็นค่าฐาน ส่วนค่าที่มากกว่า 1.5 บ่งชี้ว่าความเสี่ยงเพิ่มขึ้นอย่างมีนัยสำคัญ
- **ระดับหลักฐาน**: A = RCT/การวิเคราะห์อภิมาน (meta-analysis), B = RCT เดี่ยว/การศึกษาแบบโคฮอร์ต, C = รายงานผู้ป่วย/ความเห็นผู้เชี่ยวชาญ
- **การติดตามผล**: การตรวจทางห้องปฏิบัติการที่ควรทำในระหว่างที่ใช้ยา

<div class="warning-box__title">⚠ ใช้เป็นข้อมูลอ้างอิงเท่านั้น</div>

เครื่องมือนี้ไม่ใช่คำแนะนำทางการแพทย์ การเลือกยาต้องดูจากประวัติการรักษา ปัจจัยเสี่ยง ความสะดวกในการหายา และค่าใช้จ่ายของแต่ละคนประกอบกัน **ขอให้ตัดสินใจภายใต้คำแนะนำของบุคลากรทางการแพทย์**
