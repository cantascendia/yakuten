## การเปรียบเทียบยา

เลือกยา 2-3 ชนิดเพื่อเปรียบเทียบพารามิเตอร์สำคัญได้อย่างรวดเร็ว

**เครื่องมือนี้ช่วยให้คุณเข้าใจ:**

- ความแตกต่างของความเสี่ยง VTE (ลิ่มเลือดอุดตันในหลอดเลือดดำ) ระหว่างวิธีให้เอสโตรเจนแต่ละแบบ (ชนิดรับประทาน เทียบกับชนิดทาผ่านผิวหนัง เทียบกับชนิดฉีด)
- ข้อกำหนดในการติดตามผลและข้อห้ามใช้ของยาต้านแอนโดรเจน
- ระดับหลักฐานและช่วงขนาดยาของยาแต่ละชนิด

## วิธีตีความผลลัพธ์

- **ความเสี่ยง VTE (RR)**: ค่าความเสี่ยงสัมพัทธ์ (relative risk) โดย RR=1.0 คือค่าฐาน ส่วนค่า >1.5 บ่งชี้ว่าเพิ่มขึ้นอย่างมีนัยสำคัญ
- **ระดับหลักฐาน**: A = RCT/การวิเคราะห์อภิมาน (meta-analysis), B = RCT เดี่ยว/การศึกษาแบบโคฮอร์ต, C = รายงานผู้ป่วย/ความเห็นผู้เชี่ยวชาญ
- **การติดตามผล**: การตรวจทางห้องปฏิบัติการที่จำเป็นในระหว่างที่ใช้ยา

<div class="warning-box__title">⚠ ใช้เพื่อเป็นข้อมูลอ้างอิงเท่านั้น</div>
