เครื่องมือจำลองนี้ช่วยให้คุณเห็นภาพแนวโน้มการปรับขนาดยาในเชิงเปรียบเทียบได้ชัดเจนขึ้น จัดทำขึ้นเพื่อให้ความรู้และลดอันตราย ไม่ได้มีไว้เพื่อวางแผนการรักษาเฉพาะบุคคล

:::caution[ข้อควรทราบ]
อย่าใช้เครื่องมือจำลองนี้เป็นเครื่องคำนวณขนาดยาส่วนบุคคล ควรตีความผลลัพธ์ควบคู่ไปกับผลตรวจเลือด อาการของคุณ และคำแนะนำจากแพทย์เสมอ
:::

:::note[สถานะการแปลภาษา]
ส่วนต่อประสานของเครื่องมือแบบโต้ตอบนี้ยังอยู่ระหว่างการแปลภาษา ป้ายกำกับและข้อความช่วยเหลือบางส่วนอาจยังคงเป็นภาษาจีนอยู่ชั่วคราว
:::
