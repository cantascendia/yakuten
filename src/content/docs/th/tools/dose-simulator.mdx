เครื่องมือจำลองนี้ช่วยแสดงภาพแนวโน้มของการปรับขนาดยาในเชิงเปรียบเทียบ มีไว้เพื่อให้ความรู้และลดอันตราย ไม่ใช่เพื่อวางแผนการรักษาเฉพาะบุคคล

:::caution[ข้อควรทราบ]
อย่าใช้เครื่องมือจำลองนี้เป็นเครื่องคำนวณขนาดยาส่วนบุคคล ควรตีความผลลัพธ์ควบคู่ไปกับผลตรวจเลือด อาการ และคำแนะนำทางการแพทย์เสมอ
:::

:::note[สถานะการแปลภาษา]
ส่วนต่อประสานของเครื่องมือแบบโต้ตอบนี้ยังอยู่ระหว่างการแปลภาษา ป้ายกำกับและข้อความช่วยเหลือบางส่วนอาจยังคงเป็นภาษาจีนชั่วคราว
:::
