<WarningBox title="Limitations de l'assistant IA">
L'assistant IA est un outil d'information generaliste, pas un substitut a un avis medical. Il peut citer les guidelines et la litterature de reference, mais il ne connait ni ton historique, ni tes bilans, ni tes traitements concomitants. Aucun echange avec l'assistant n'est enregistre -- la conversation est ephemere et n'est jamais transmise a nos serveurs de donnees.
</WarningBox>

## Protection de tes donnees

Tous les outils d'analyse et les outils pratiques sont construits selon le principe suivant :

- **Zero transmission** : tes saisies et tes resultats restent dans ton navigateur. Aucun appel serveur n'est effectue.
- **Zero stockage cote serveur** : meme si ton navigateur perd la connexion pendant l'utilisation, aucune donnee n'a ete envoyee.
- **Mode classique** : le mode par defaut de l'outil de bilan sanguin est entierement sans stockage -- tes valeurs disparaissent a la fermeture de l'onglet.
- **Mode sakura (手帐)** : le mode sakura de l'outil de bilan sanguin enregistre tes donnees dans le `localStorage` de ton navigateur, sur ton appareil uniquement. Tu peux les supprimer a tout moment via le bouton "Effacer toutes les donnees".
- **Mesure d'audience** : le site utilise Google Analytics 4 (cookies ; tu peux le bloquer via ton navigateur ou un bloqueur de publicites) ainsi que Vercel Web Analytics et Speed Insights pour des statistiques de visite agregees. Tes donnees de sante, tes saisies et tes conversations avec l'IA ne leur sont jamais envoyees, et aucun pixel publicitaire ou de reseau social n'est utilise. Details : [Confidentialite](/fr/about/#confidentialité)
- **Code open source** : le code complet est consultable sur [GitHub](https://github.com/Loveil381/yakuten). Tu peux verifier toi-meme qu'aucune donnee n'est transmise.

<DangerBox title="En cas d'urgence medicale, ne pas utiliser les outils -- appeler le 15 ou le 112">
Si tu constates des symptomes alarmants (douleur thoracique, gonflement unilateral d'une jambe, essoufflement, jaunisse, cephalee severe soudaine), n'utilise pas les outils pour tenter un autodiagnostic. **Appelle immediatement le 15 (SAMU) ou le 112.**
</DangerBox>
