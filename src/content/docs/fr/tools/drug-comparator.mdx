## Comparaison des médicaments

Sélectionnez 2 à 3 médicaments pour comparer rapidement leurs paramètres clés.

**Cet outil vous aide à comprendre :**

- Les différences de risque de TEV (thromboembolie veineuse) selon la voie d'administration des œstrogènes (orale vs transdermique vs injectable)
- Les exigences de surveillance et les contre-indications des anti-androgènes
- Les niveaux de preuve et les fourchettes posologiques de chaque médicament

## Comment interpréter les résultats

- **Risque de TEV (RR)** : valeur de risque relatif. RR=1,0 correspond à la valeur de référence ; > 1,5 indique une augmentation significative
- **Niveau de preuve** : A = ECR/méta-analyse, B = ECR unique/étude de cohorte, C = série de cas/avis d'expert
- **Surveillance** : examens biologiques nécessaires pendant l'utilisation du médicament
