Este simulador ayuda a visualizar tendencias relativas de dosificación. Está pensado con fines educativos y de reducción de daños, no para la planificación individualizada del tratamiento.

:::caution[Importante]
No uses este simulador como una calculadora personal de prescripción. Interpreta siempre los resultados junto con los análisis de sangre, los síntomas y la orientación clínica.
:::

:::note[Estado de la localización]
La interfaz de la herramienta interactiva todavía se está localizando. Es posible que algunas etiquetas y textos de ayuda permanezcan temporalmente en chino.
:::
