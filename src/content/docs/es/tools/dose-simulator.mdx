Este simulador te ayuda a visualizar las tendencias relativas de dosificación. Está pensado con fines educativos y de reducción de daños, no para planificar un tratamiento de forma individualizada.

:::caution[Importante]
No uses este simulador como una calculadora personal de prescripción. Interpreta siempre los resultados teniendo en cuenta tus análisis de sangre, tus síntomas y la orientación de tu médico.
:::
