## Paghahambing ng mga Gamot

Pumili ng 2-3 gamot para mabilis na maihambing nang magkatabi ang kanilang mga pangunahing parameter.

**Tutulong sa iyo ang kasangkapang ito na maunawaan:**

- Ang pagkakaiba sa panganib ng VTE (venous thromboembolism) ayon sa ruta ng estrogen (oral kumpara sa transdermal kumpara sa iniksiyon)
- Ang mga kailangang pagmamanman (monitoring) at contraindication para sa mga anti-androgen
- Ang antas ng ebidensiya at saklaw ng dosis para sa bawat gamot

## Paano Basahin ang mga Resulta

- **Panganib ng VTE (RR)**: Ang halaga ng relative risk. Ang RR=1.0 ang baseline; ang higit sa 1.5 ay tanda ng malaking pagtaas
- **Antas ng Ebidensiya**: A = RCT/Meta-analysis, B = Iisang RCT/Cohort study, C = Case report/Opinyon ng eksperto
- **Pagmamanman (Monitoring)**: Ang mga lab test na kailangang isagawa habang ginagamit ang gamot
