## Paghahambing ng mga Gamot

Pumili ng 2-3 gamot upang mabilis na maihambing ang kanilang mga pangunahing parameter.

**Tumutulong ang kasangkapang ito upang maunawaan mo:**

- Ang pagkakaiba sa panganib ng VTE (venous thromboembolism) sa pagitan ng mga ruta ng estrogen (oral vs transdermal vs iniksiyon)
- Ang mga kinakailangang pagmamanman (monitoring) at contraindication para sa mga anti-androgen
- Ang mga antas ng ebidensiya at saklaw ng dosis para sa bawat gamot

## Paano Bigyang-Kahulugan ang mga Resulta

- **Panganib ng VTE (RR)**: Halaga ng relative risk. Ang RR=1.0 ay baseline; ang >1.5 ay nagpapahiwatig ng malaking pagtaas
- **Antas ng Ebidensiya**: A = RCT/Meta-analysis, B = Iisang RCT/Cohort study, C = Case report/Opinyon ng eksperto
- **Pagmamanman (Monitoring)**: Mga lab test na kinakailangan habang ginagamit ang gamot
