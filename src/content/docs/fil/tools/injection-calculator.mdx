Gamitin ang tool na ito para tantyahin ang konsentrasyon at i-convert ang dami (volume) para sa mga injectable na preparasyon ng estradiol. Sangguniang tulong lang ito, hindi personal na rekomendasyon sa dosing.

Laging tiyakin muna ang konsentrasyon ng vial, ang mga yunit, at ang ruta bago gamitin ang anumang kalkulasyon sa aktwal na paggamit.
:::
