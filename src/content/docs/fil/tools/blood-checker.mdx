Gamitin ang tool na ito para sa mabilis na biswal na pagsusuri ng mga karaniwang lab marker sa HRT tulad ng estradiol, testosterone, prolactin, mga enzyme ng atay, potassium, hemoglobin, at D-dimer.

:::caution[Mahalaga]
Ang tool na ito ay pang-edukasyon lamang. Ang abnormal na resulta, malalang sintomas, o anumang emerhensiya ay dapat palaging suriin ng kuwalipikadong klinisyan.
:::

:::note[Katayuan ng lokalisasyon]
Ang interface ng interactive na tool ay isinasalin pa. Maaaring pansamantalang manatiling Tsino ang ilang label ng kontrol at teksto ng babala.
:::
