Gamitin ang tool na ito para sa mabilis at biswal na pagsusuri ng mga karaniwang lab marker sa HRT gaya ng estradiol, testosterone, prolactin, mga enzyme ng atay, potassium, hemoglobin, at D-dimer.

:::caution[Mahalaga]
Pang-edukasyon lamang ang tool na ito. Ang abnormal na resulta, malalang sintomas, o anumang alalahaning pang-emerhensiya ay dapat laging suriin ng kuwalipikadong klinisyan.
:::

:::note[Katayuan ng lokalisasyon]
Isinasalin pa ang interface ng interactive na tool. Maaaring pansamantalang manatiling Tsino ang ilang label ng kontrol at teksto ng babala.
:::
