## Миссия

**Доказательная база · Снижение вреда · Путь к медицинской помощи**

HRT Yakuten — это информационный сайт о базовых принципах безопасности для трансгендерных женщин китайскоязычного сообщества, применяющих ЗГТ (заместительную гормональную терапию). Наша цель — не заменить врача, а помочь тем, кто уже принимает гормональную терапию или собирается её начать:

- **Понимать результаты анализов крови** и знать, какие отклонения требуют обращения к врачу
- **Узнать реальные риски препаратов**, а не полагаться на слухи в сообществе и непроверенные личные истории
- **Распознавать тревожные признаки неотложных состояний** (ТГВ (тромбоз глубоких вен), поражение печени, менингиома) и принимать верные решения в критические моменты
- **Найти дружественные к трансгендерным людям медицинские ресурсы** и перейти от самостоятельного приёма (DIY) к терапии под наблюдением врача

### Чем этот сайт НЕ является

- ❌ Это не энциклопедия и не медицинский учебник
- ❌ Это не форум, не сообщество и не социальная платформа
- ❌ Это не канал для покупки препаратов и не сайт с рекомендациями аптек
- ❌ Здесь не дают индивидуальных рекомендаций по дозировке («вам следует принимать X мг»)

## Источники информации

Всё медицинское содержание этого сайта основано на следующих международных клинических руководствах и рецензируемой литературе:

| Источник | Описание |

| **WPATH SOC 8 (2022)** | *Standards of Care for the Health of Transgender and Gender Diverse People*, версия 8 |
| **UCSF Transgender Care** | Калифорнийский университет в Сан-Франциско — руководство по медицинской помощи трансгендерным людям |
| **EMA (2020)** | Ограничения Европейского агентства по лекарственным средствам и оценка безопасности CPA |
| **PubMed / PMC** | Рецензируемые оригинальные исследовательские работы (каждая ссылка содержит DOI) |

Надстрочные номера рядом с каждой медицинской рекомендацией (например, <sup>[1]</sup>) ведут к конкретному источнику. **Нет ссылки — нет содержания** — это незыблемое правило сайта.

## Процесс проверки содержания

| Этап | Стандарт |
|------|----------|
| **Требование к ссылкам** | Каждая клиническая рекомендация должна восходить хотя бы к одной рецензируемой работе или международному руководству |
| **Перекрёстная проверка** | Диапазоны доз препаратов должны подтверждаться перекрёстно по ≥2 независимым источникам (например, WPATH + Endocrine Society + UCSF) |

| **Цикл обновления** | Содержание проверяется на актуальность ежеквартально и обновляется на основе вновь опубликованной литературы |

## Техническая реализация

| Технология | Назначение |
|------------|---------|
| **Astro + Starlight** | Генерация статического сайта — по умолчанию ноль JS, крайне быстрая загрузка |
| **React Islands** | JS на стороне клиента только для интерактивных инструментов (проверка анализов крови, симулятор дозы и т. д.) |
| **Pagefind** | Статический поисковый индекс с поддержкой китайского / английского / японского языков |
| **Vercel** | Статический хостинг + Edge Functions (вопросы и ответы с ИИ) |
| **Открытый исходный код** | Полный исходный код доступен на [GitHub](https://github.com/cantascendia/yakuten) |

## Конфиденциальность

**Этот сайт не собирает и не хранит никаких персональных данных.**

| Категория | Мера |
|----------|---------|
| **Инструмент анализов крови** | Расчёт полностью на стороне клиента (front-end JavaScript) — введённые вами данные никогда не покидают браузер и не отправляются ни на один сервер |
| **Вопросы и ответы с ИИ** | Диалоги обрабатываются в реальном времени через Edge Functions — ничего не сохраняется, не логируется и не используется для обучения |
| **Аналитика** | Vercel Web Analytics и Speed Insights — только агрегированные просмотры страниц и метрики производительности; без cookie, без хранения персональных идентификаторов, без межсайтового отслеживания |
| **Отслеживание** | Нет Google Analytics, нет встроенных трекеров социальных сетей или рекламы — кроме упомянутой выше агрегированной аналитики Vercel |
| **Cookie** | Используются только для настройки темы (тёмный / светлый режим), не для отслеживания |
| **Реклама** | Отсутствует и никогда не появится |

## Отказ от ответственности

Содержание этого сайта предназначено **только для образовательных и информационных целей** и не является медицинской консультацией.

- Этот сайт не может заменить очную диагностику и лечение у квалифицированного врача
- Приём, корректировку и отмену препаратов следует проводить под руководством квалифицированного медицинского специалиста
- Если у вас возникают любые неотложные симптомы (одностороннее отёк/боль в ноге, внезапная боль в груди, желтуха и т. д.), немедленно прекратите приём препаратов и обратитесь в ближайшее отделение неотложной помощи
- Этот сайт не несёт ответственности за любые медицинские последствия, вызванные использованием его содержания

**Самолечение (DIY) сопряжено с реальными рисками.** Этот сайт призван помочь вам применять препараты безопаснее, но самый надёжный путь — всегда проходить ЗГТ под наблюдением врача.
