Этот симулятор позволяет наглядно увидеть относительные тенденции дозирования. Он создан для просвещения и снижения вреда, а не для составления индивидуального плана лечения.

:::caution[Важно]
Не используйте этот симулятор как личный калькулятор дозы. Любой результат оценивайте только в связке с анализами крови, самочувствием и рекомендациями вашего врача.
:::

:::note[Статус локализации]
Интерфейс интерактивного инструмента локализуется поэтапно. Часть подписей и вспомогательных пояснений может временно отображаться на английском или китайском языке.
:::
