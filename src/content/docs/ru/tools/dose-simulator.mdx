Этот симулятор помогает наглядно представить относительные тенденции дозирования. Он предназначен для просвещения и снижения вреда, а не для составления индивидуального плана лечения.

:::caution[Важно]
Не используйте этот симулятор как персональный калькулятор для расчёта дозы. Всегда оценивайте результаты в совокупности с данными анализов крови, симптомами и рекомендациями врача.
:::

:::note[Статус локализации]
Интерфейс интерактивного инструмента всё ещё находится в процессе локализации. Часть подписей и вспомогательного текста может временно оставаться на китайском языке.
:::
