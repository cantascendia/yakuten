С помощью этого инструмента можно прикинуть концентрацию и пересчитать объёмы для инъекционных препаратов эстрадиола. Это вспомогательная справка, а не индивидуальная рекомендация по дозированию.

:::caution[Важно]
Прежде чем применять любой расчёт на практике, обязательно сверяйтесь с концентрацией во флаконе, единицами измерения и путём введения.
:::

:::note[Статус локализации]
Интерфейс интерактивного инструмента локализуется поэтапно. Часть подписей и пояснений может временно отображаться на английском или китайском языке.
:::
