Используйте этот инструмент для быстрой визуальной оценки основных лабораторных маркеров при ГЗТ (гормонозаместительной терапии): эстрадиола, тестостерона, пролактина, печёночных ферментов, калия, гемоглобина и D-димера.

:::caution[Важно]
Этот инструмент носит исключительно образовательный характер. Отклонения в результатах, тяжёлые симптомы и неотложные состояния всегда должны оцениваться квалифицированным врачом.
:::

:::note[Статус локализации]
Интерфейс интерактивного инструмента всё ещё находится в процессе локализации. Часть подписей к элементам управления и предупреждающих сообщений может временно оставаться на китайском языке.
:::
