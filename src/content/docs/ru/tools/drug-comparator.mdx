## Сравнение препаратов

Выберите 2–3 препарата, чтобы быстро сравнить их ключевые параметры.

**Этот инструмент помогает понять:**

- Различия в риске ВТЭ (VTE) между путями введения эстрогена (перорально, трансдермально, инъекционно)
- Требования к мониторингу и противопоказания для антиандрогенов
- Уровни доказательности и диапазоны доз для каждого препарата

## Как интерпретировать результаты

- **Риск ВТЭ (RR)**: значение относительного риска. RR=1.0 — это базовый уровень; >1.5 указывает на значимое повышение
- **Уровень доказательности**: A = РКИ/метаанализ, B = одиночное РКИ/когортное исследование, C = клинический случай/мнение экспертов
- **Мониторинг**: лабораторные анализы, необходимые при приёме препарата
