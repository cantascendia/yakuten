## Сравнение препаратов

Выберите 2–3 препарата, чтобы быстро сопоставить их ключевые параметры бок о бок.

**Этот инструмент поможет вам разобраться в следующем:**

- Чем отличается риск ВТЭ (VTE) при разных путях введения эстрогена — перорально, трансдермально и в инъекциях
- Какие требования к мониторингу и какие противопоказания существуют у антиандрогенов
- Какие уровни доказательности и диапазоны доз характерны для каждого препарата

## Как читать результаты

- **Риск ВТЭ (RR)**: значение относительного риска. RR=1.0 — это базовый уровень; значение >1.5 говорит о значимом повышении риска
- **Уровень доказательности**: A = РКИ/метаанализ, B = одиночное РКИ/когортное исследование, C = клинический случай/мнение экспертов
- **Мониторинг**: лабораторные анализы, которые нужно сдавать во время приёма препарата
