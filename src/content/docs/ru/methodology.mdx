На этой странице описано, как пишется, рецензируется и обновляется каждый материал HRT Pharmacopoeia. Это наше обязательство перед читателями: **текст, не прошедший этот процесс, не публикуется**.

## 1. Три основных принципа

1. **Нет утверждения без источника**: каждое медицинское утверждение должно опираться как минимум на одну ссылку с DOI или на международное руководство; если источник найти невозможно, утверждение либо помечается как <EvidenceBadge level="X" />, либо удаляется.
2. **Перекрёстная сверка данных о дозировках**: дозы для назначения должны встречаться не менее чем в двух независимых авторитетных источниках (WPATH SOC 8 · Endocrine Society 2017 · UCSF · EMA и им подобных).
3. **Избегайте категоричных формулировок**: вместо «обязательно / всегда / никогда» используйте «как правило / рекомендуется / в подавляющем большинстве случаев».

## 2. Полный рабочий процесс

### 1. Выбор темы
- Темы выбираются исходя из поискового спроса, вопросов читателей, обновлений руководств и крупных предупреждений о безопасности (EMA/FDA)
- На каждой странице перечислены 3–7 конкретных вопросов, на которые она должна ответить
- Целевая аудитория (пациент / врач первичного звена / член семьи) определяется заранее

### 2. Поиск литературы
- Основные источники: PubMed, Cochrane, официальные сайты руководств, обзоры Transfemscience
- Исключаются: анонимные посты на форумах, коммерческие сайты, блоги без рецензирования
- Для каждого ключевого утверждения фиксируется первоисточник (предпочтительно DOI; иначе — данные о публикации в журнале)

### 3. Градация доказательности
Оценка по силе дизайна исследования:

| Уровень | Значение | Пример доказательств |
|---|---|---|
| <EvidenceBadge level="A" /> | Высокий | Множество РКИ, систематические обзоры / метаанализы, явная рекомендация международного руководства |
| <EvidenceBadge level="B" /> | Умеренный | Единичное РКИ, несколько проспективных когорт |
| <EvidenceBadge level="C" /> | Низкий | Описания случаев, ретроспективные исследования, мнение экспертов |
| <EvidenceBadge level="X" /> | Отсутствует | Сообщество, личный опыт, умозаключения |

### 4. Подготовка черновика
- Используются общие компоненты: `<DrugInfoBox>`, `<DoseTable>`, `<CitationRef>`, `<WarningBox>`, `<EmergencyBanner>` и другие
- Во frontmatter фиксируются `evidenceLevel`, `lastReviewed` и `references` (контролируется CI)
- Таблицы доз автоматически проверяют верхние пределы и противопоказанные комбинации

### 5. Перекрёстная проверка двумя редакторами
- Автор завершает черновик → второй редактор независимо сверяет каждую ссылку `<CitationRef>` с первоисточником
- Несоответствия или преувеличения → возврат на доработку
- Если первоисточник был отозван или исправлен → поиск и замена по всему сайту

### 6. Рецензирование медицинским консультантом
- Консультанты по эндокринологии / психиатрии / юридическим вопросам назначаются в зависимости от темы
- Протоколы рецензирования, включая особые мнения и итоговые решения, сохраняются в архиве
- Если не удаётся привлечь квалифицированного рецензента, тема не публикуется

### 7. Контроль качества публикации и доступности
- `npm run astro check` + Lighthouse (SEO ≥ 95 / A11y ≥ 95)
- Проверяются цветовой контраст, доступность с клавиатуры, семантика для программ экранного доступа
- Проверены мобильные контрольные точки и резервный вариант `prefers-reduced-motion`

### 8. Плановый пересмотр
- По умолчанию повторный пересмотр каждые **12 месяцев** с обновлением `lastReviewed`
- Страницы высокого риска (риски, предельные дозы, неотложные состояния) пересматриваются каждые **6 месяцев**
- Существенное изменение руководства → инкрементальное обновление в течение 48 часов

## 3. Исправление ошибок

Когда читатели обнаруживают фактические ошибки, расхождения в ссылках или устаревший контент:

1. Отправьте сообщение через [форму обратной связи](https://wj.qq.com/s2/16576000/5fe5/) или GitHub Issue
2. Первичный ответ в течение 72 часов
3. После подтверждения фактической ошибки в начало страницы добавляется **уведомление об опечатке (erratum)**, а в истории версий фиксируются исходная ошибка и дата исправления
4. О существенных исправлениях уведомляются подписчики по email / RSS / Telegram
