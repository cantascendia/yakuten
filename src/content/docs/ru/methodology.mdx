Эта страница рассказывает, как пишется, проверяется и обновляется каждый материал HRT Pharmacopoeia. Это наше обещание читателям: **текст, не прошедший этот путь, мы не публикуем**.

## 1. Три главных принципа

1. **Никаких утверждений без источника**: за каждым медицинским утверждением должна стоять хотя бы одна ссылка с DOI или международное руководство; если источник найти не удаётся, утверждение либо получает отметку <EvidenceBadge level="X" />, либо убирается.
2. **Дозы — только по двум независимым источникам**: данные о назначаемых дозах должны встречаться не менее чем в двух независимых авторитетных источниках (WPATH SOC 8 · Endocrine Society 2017 · UCSF · EMA и подобных им).
3. **Без категоричности**: вместо «обязательно / всегда / никогда» мы пишем «как правило / рекомендуется / в подавляющем большинстве случаев».

## 2. Полный рабочий процесс

### 1. Выбор темы
- Темы выбираются по поисковому спросу, вопросам читателей, обновлениям руководств и крупным предупреждениям о безопасности (EMA/FDA)
- Для каждой страницы заранее формулируются 3–7 конкретных вопросов, на которые она должна ответить
- Целевая аудитория (пациент / врач первичного звена / близкий человек) определяется с самого начала

### 2. Поиск литературы
- Основные источники: PubMed, Cochrane, официальные сайты руководств, обзоры Transfemscience
- Не используются: анонимные посты на форумах, коммерческие сайты, блоги без рецензирования
- Для каждого ключевого утверждения фиксируется первоисточник (предпочтительно DOI; иначе — выходные данные публикации в журнале)

### 3. Градация доказательности
Оценка по силе дизайна исследования:

| Уровень | Значение | Пример доказательств |
|---|---|---|
| <EvidenceBadge level="A" /> | Высокий | Множество РКИ, систематические обзоры / метаанализы, явная рекомендация международного руководства |
| <EvidenceBadge level="B" /> | Умеренный | Единичное РКИ, несколько проспективных когорт |
| <EvidenceBadge level="C" /> | Низкий | Описания случаев, ретроспективные исследования, мнение экспертов |
| <EvidenceBadge level="X" /> | Отсутствует | Опыт сообщества, личный опыт, умозаключения |

### 4. Подготовка черновика
- Используются общие компоненты: `<DrugInfoBox>`, `<DoseTable>`, `<CitationRef>`, `<WarningBox>`, `<EmergencyBanner>` и другие
- Во frontmatter фиксируются `evidenceLevel`, `lastReviewed` и `references` (это контролирует CI)
- Таблицы доз автоматически проверяют верхние пределы и противопоказанные сочетания

### 5. Перекрёстная проверка двумя редакторами
- Автор завершает черновик → второй редактор самостоятельно сверяет каждую ссылку `<CitationRef>` с первоисточником
- Несоответствия или преувеличения → возврат на доработку
- Если первоисточник отозван или исправлен → поиск и замена по всему сайту

### 6. Рецензирование медицинским консультантом
- Консультанты по эндокринологии / психиатрии / юридическим вопросам назначаются в зависимости от темы
- Протоколы рецензирования, включая особые мнения и итоговые решения, хранятся в архиве
- Если привлечь квалифицированного рецензента не удаётся, тема не публикуется

### 7. Контроль качества публикации и доступности
- `npm run astro check` + Lighthouse (SEO ≥ 95 / A11y ≥ 95)
- Проверяются цветовой контраст, доступность с клавиатуры, семантика для программ экранного доступа
- Проверены мобильные контрольные точки и резервный вариант `prefers-reduced-motion`

### 8. Плановый пересмотр
- По умолчанию повторный пересмотр каждые **12 месяцев** с обновлением `lastReviewed`
- Страницы высокого риска (риски, предельные дозы, неотложные состояния) пересматриваются каждые **6 месяцев**
- Существенное изменение руководства → инкрементальное обновление в течение 48 часов

## 3. Исправление ошибок

Когда читатели находят фактические ошибки, расхождения в ссылках или устаревший контент:

1. Напишите нам через [форму обратной связи](https://wj.qq.com/s2/16576000/5fe5/) или GitHub Issue
2. Первичный ответ в течение 72 часов
3. После подтверждения фактической ошибки в начало страницы добавляется **уведомление об опечатке (erratum)**, а в истории версий фиксируются исходная ошибка и дата исправления
4. О существенных исправлениях мы сообщаем подписчикам по email / RSS / Telegram

## 4. Заявление о конфликте интересов

- У этого сайта нет коммерческого спонсорства, рекламы лекарств и комиссий с покупок
- Эксплуатационные расходы волонтёры оплачивают из собственных средств; мы принимаем пожертвования от open-source-сообщества
- Редакторы и медицинские консультанты подписывают декларации о конфликте интересов; препараты, с которыми связаны действующие отношения по назначению, не рецензируются независимо стороной, имеющей конфликт интересов
