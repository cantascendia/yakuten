## プライバシーへの約束

- AIアシスタントを除くすべてのツールは**ブラウザのローカルで動作**し、入力内容はサーバーに送信されません
- AIアシスタントへの質問は、本サイトのサーバーを経由して外部の AI サービス（Google Gemini、OpenAI）に送られます。本サイトは**会話を保存しません**が、各社の規約により送信内容がサービス改善に使われる場合があります。氏名・電話番号・身分証の番号などは入力しないでください
- 「血液検査手帳」の記録と（オンにした場合の）AI 会話履歴は、**あなたのローカル端末の `localStorage`** にのみ保存されます。いつでもワンタップで全消去できます
- アクセス集計には Google Analytics 4（Cookie を使用。ブラウザ設定や広告ブロッカーで無効化できます）と Vercel Web Analytics / Speed Insights を使っています。健康データ、ツールへの入力、AI との会話が解析サービスに送られることはなく、広告や SNS のトラッキングピクセルも使用していません。詳しくは[プライバシー](/ja/about/#プライバシー)をご覧ください

## 注意

これらのツールは診断を提供するものではありません。**もし何らかの異常な結果が出た場合は、速やかに医療機関を受診し、医師に相談することをおすすめします**。いま緊急の症状が出ている場合は、ただちに **119** に電話するか、最寄りの救急外来を受診し、[リスクと急性症状の見分け方](/ja/risks/) をよくお読みください。
