## プライバシーへの約束

- すべてのツールは**ブラウザのローカルで動作**し、あなたの入力データは通常どのサーバーにも送信されません
- AIアシスタントは**あなたの会話履歴を保存しません**。ページを閉じれば通常ただちに消去されます
- 「血液検査手帳」機能は、記録を**あなたのローカル端末の `localStorage`** にのみ書き込みます。いつでもワンタップで全消去できます
- サイト全体の分析には Vercel Web Analytics と Speed Insights を使用しています（Cookie なし、集計統計のみ、個人を特定しません）。Google Analytics やソーシャルメディアのトラッカーは使用していません

## 注意

これらのツールは診断を提供するものではありません。**もし何らかの異常な結果が出た場合は、速やかに医療機関を受診し、医師に相談することをおすすめします**。いま緊急の症状が出ている場合は、ただちに **119** に電話するか、最寄りの救急外来を受診し、[リスクと急性症状の見分け方](/ja/risks/) をよくお読みください。
