医療コンテンツの正確さは、コミュニティの健康と安全を守るための重要な土台です。読んでいる途中で誤字、古くなった情報、あるいは建設的な改善のご提案を見つけた場合は、いつでも以下のチャンネルから遠慮なくお知らせください。

<WarningBox>
**用薬の安全に関わる緊急の修正報告（例：用量表示の誤記、重要な禁忌の見落とし、急変時の注意喚起の欠落など）については、編集チームが通常 48 時間以内に優先して審査と更新を完了します。**
</WarningBox>

## コンテンツの修正

閲覧中に医療の専門的な記述やデータに誤りを見つけた場合は、GitHub Issue から構造化された修正報告を送っていただくことをおすすめします。

**報告の際、以下の情報を併せてご提供いただけると、私たちの再確認が大幅に速くなります：**
- 誤りのあるページのリンク（URL）
- 誤りのある箇所の具体的な文（原文の引用）
- あなたが提案する修正後の科学的な表現
- その修正を裏づけるエビデンスとなる参考文献（DOI 番号、または信頼できる公開文献へのリンクなど）

## 修正の審査・対応フロー

1. **受付・登録** —— あなたの修正報告は、システムによって正式に審査キューへ登録されます。
2. **エビデンスの確認** —— 編集チームが、ご提供いただいた修正案と添付文献を厳密に確認します。
3. **修正の反映** —— 確認が取れ次第、影響を受けるページを直ちに更新し、コンテンツの審査日を改めて記載します。
4. **ステータスの確認** —— 修正の公開後、対応する GitHub Issue またはフィードバックチャンネルにて、問題が解決したことを返信でお知らせします。

| 修正・フィードバックの種類 | 想定される対応の目安 |
|----------------|----------------|
| 安全に関わるもの（用量／禁忌／急変） | 48 時間以内 |
| 医療の専門データの誤記 | 1 週間以内 |
| 表現の流暢さや翻訳の改善 | 1〜2 週間 |
| サイトのインタラクティブ機能の提案 | 技術開発のスケジュールに応じて |
