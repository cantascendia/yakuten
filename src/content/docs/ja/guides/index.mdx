薬物詳解ページが「これはどんな薬か」を解説するためのものだとすれば、実践ガイドは「自分は何をすればよいのか」を伝えるためのものです。本コーナーは、あなたが実際に直面しうる意思決定の場面を中心に構成されています。各ガイドは行動の順序に沿って、事前の身体検査、具体的なパラメータ、再検査のタイミング、受診前の準備を整理しており、薬理の細かい説明を繰り返すことは避け、簡潔で要点を押さえた内容を目指しています。

## 再訪される方へ

どのガイドを読めばよいかすぐに判断できない場合は、以下の説明から手早く見分けることができます。

- **接種、あるいは最初の1回目の注射を行う前**であれば、[初回注射 完全ガイド](/ja/guides/first-injection/) から読み始めることをおすすめします。
- **すでに何らかの抗アンドロゲン薬を使用しているが、指標の異常や薬剤の入手困難という問題に直面している**場合は、[抗アンドロゲン切り替え 完全ガイド](/ja/guides/switch-antiandrogen/) を参照してください。
- **すでにエストラジオールを使用しているが、安全性や利便性を考慮して投与経路を変更したい**場合は、[E2 投与経路の切り替え 完全ガイド](/ja/guides/switch-e2-route/) をご覧ください。

より体系的な情報が必要であれば、以下のページから始めることもできます。

- まだ投薬を始めていない → [投薬前：準備はできていますか？](/ja/before-you-start/)
- 自分がどの段階にいるのか分からない → [HRT経路マップ](/ja/pathway/)
- 複数の薬物のパラメータを比較したい → [薬物比較ツール](/ja/tools/drug-comparator/)

## 今後の計画

現在のところ、私たちのガイドは主に最もよくある3つの意思決定の場面をカバーしています。今後は、皆さんからのフィードバックをもとに、より多くのタスク型ガイドを段階的に追加していく予定です（たとえば、初回の血液検査レポートの読み解き方、HRT とカウンセリングの関係をどう調整するか、長期フォローアップの科学的なペースなど）。もし、あなたが直面している場面がまだ収録されていない場合は、まず [AI 問答アシスタント](/ja/tools/ai-assistant/) で初歩的な減害アドバイスを得ることができます。また、[本サイトについて](/ja/about/) のページにいつでもメッセージを残していただければ、私たちが継続的にコンテンツを改善していく助けになります。
