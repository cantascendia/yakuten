Use esta ferramenta para uma verificação visual rápida de marcadores laboratoriais comuns na TRH (Terapia de Reposição Hormonal), como estradiol, testosterona, prolactina, enzimas hepáticas, potássio, hemoglobina e dímero-D.

:::caution[Importante]
Esta ferramenta é apenas educativa. Resultados anormais, sintomas graves ou situações de emergência devem sempre ser avaliados por um profissional de saúde qualificado.
:::
