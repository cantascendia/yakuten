## Medikamentenvergleich

Wählen Sie 2–3 Medikamente aus, um ihre wichtigsten Parameter rasch zu vergleichen.

**Dieses Tool hilft Ihnen, Folgendes zu verstehen:**

- Unterschiede im VTE-Risiko zwischen den Estrogen-Applikationswegen (oral vs. transdermal vs. Injektion)
- Überwachungsanforderungen und Kontraindikationen von Antiandrogenen
- Evidenzgrade und Dosisbereiche der einzelnen Medikamente

<DrugComparator client:visible />

## So interpretieren Sie die Ergebnisse

- **VTE-Risiko (RR)**: relativer Risikowert. RR=1.0 ist die Ausgangsbasis; >1.5 weist auf eine deutliche Erhöhung hin
- **Evidenzgrad**: A = RCT/Metaanalyse, B = einzelne RCT/Kohortenstudie, C = Fallbericht/Expertenmeinung
- **Überwachung**: Laboruntersuchungen, die während der Anwendung des Medikaments erforderlich sind
