Mit diesem Werkzeug lassen sich gängige HRT-Laborwerte wie Östradiol, Testosteron, Prolaktin, Leberenzyme, Kalium, Hämoglobin und D-Dimer rasch optisch einordnen.

:::caution[Wichtig]
Dieses Werkzeug dient ausschließlich der Information. Auffällige Werte, schwere Symptome oder ein Verdacht auf einen Notfall sollten stets von einer qualifizierten Fachperson abgeklärt werden.
:::

:::note[Stand der Lokalisierung]
Die Oberfläche des interaktiven Werkzeugs wird noch lokalisiert. Einige Bedienelemente und Warnhinweise können vorübergehend auf Chinesisch erscheinen.
:::
